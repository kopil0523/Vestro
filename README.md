# Vestro - Restaurant Landing Page

A modern, responsive restaurant landing page for **Vestro**, featuring a dark theme with gold accents.

## Features

- Responsive design (mobile & desktop)
- Dark theme with elegant gold accents
- Full menu with images and prices
- Order form for online ordering
- Location & business hours section
- Smooth scrolling navigation
- Hover effects on menu cards
- Parallax banner

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, CSS Variables)

1. Clone the repository
2. Open `index.html` in any web browser
3. No build tools or dependencies required
